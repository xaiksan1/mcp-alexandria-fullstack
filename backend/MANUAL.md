## 📖 COUCHE 3 — RECETTES

> Comment faire des choses concrètes. Copie-colle et adapte.

### 📄 Spawner un agent depuis un paper ou un PDF

1. Dépose ton fichier dans `alexandria/ADAM/pdf/` ou n'importe où
2. Déclenche `📄` avec `{"source": "/chemin/vers/paper.md"}`
3. L'agent est généré dans `backend/spawned_agents/` et prêt à tourner
4. Même chose avec `🖥️` pour un serveur MCP au lieu d'un agent CLI

**Exemple :** `dispatch_emoji("📄", {"source": "pdf/mon_paper.md"})`

### ✨ Enregistrer un nouvel emoji dans le système

1. Choisis un emoji libre, un node_id SESHAT, et un action_type
2. Via MCP : outil `register_emoji`
3. Via CLI : `python3 trunk_dispatcher.py` (liste les mappings)
4. Le manuel se met à jour automatiquement après l'enregistrement

**Exemple :** `register_emoji("🛡️", "aegis", "AEGIS", "agent2cli", "aegis.py")`

### 🌡️ Lancer un agent en interface texte (TUI)

1. Déclenche un emoji `agent2tui` : `🌡️` (Thermal Ratchet) ou `🕸️` (SERENA)
2. Un terminal s'ouvre avec l'agent en mode interactif
3. Ctrl+C pour fermer

**Exemple :** `dispatch_emoji("🌡️")`

### 🤖 Poster un état sur Slack

1. `👤` → #alexandria-human (pour les humains)
2. `🤖` → #alexandria-llm (pour les agents IA)
3. Ajoute `text` dans les args pour personnaliser le message
4. Ajoute `webhook_url` dans le meta du mapping pour activer l'envoi

**Exemple :** `dispatch_emoji("🤖", {"text": "ADAM : opérationnel, 67 nœuds actifs"})`

### ⬡ Voir le mind-map SESHAT en direct

1. Déclenche `⬡` pour ouvrir Alexandria Core
2. `📜` → dossier Memory, `🌸` → carte Stigmergy
3. Chaque nœud est cliquable et affiche ses pheromone trails

**Exemple :** `dispatch_emoji("⬡")`

### 📖 Régénérer ce manuel manuellement

1. Via MCP : outil `regenerate_manual`
2. Via CLI : `python3 manual_generator.py`
3. Via CLI avec preview : `python3 manual_generator.py --preview`
4. Poste sur Slack : `python3 manual_generator.py --slack #alexandria-human`

**Exemple :** `python3 manual_generator.py --preview`
