# Paper2Agents (Backend)

Ce dossier contient la logique serveur du système Paper Intelligence.

## 🎯 Objectif
Transformer des papiers scientifiques (PDF/Text) en agents IA structurés et opérationnels.

## 🛠️ Composants (Prévus)
- **Ingestor** : Extraction de texte et métadonnées.
- **Modeler** : Traduction des concepts théoriques en paramètres d'agent.
- **Spawn Engine** : Création d'instances d'agents via ADK.
- **Incentive Loop** : Validation et récompense (Basé sur le système Pioneer).

## 🚀 Utilisation
Référez-vous aux exemples dans `../examples/pioneer/` pour voir une implémentation fonctionnelle du cycle d'évaluation.
